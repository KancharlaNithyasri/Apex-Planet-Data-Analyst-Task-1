# Apex-Planet-Data-Analyst-Task-1
Task 1: Data Immersion & Wrangling for the Superstore Dataset - Internship Project

Company: Apex Planet Software Solutions Pvt Limited  


Project Objective:
The goal of this task was to perform data "cleaning and immersion." I transformed a raw sales dataset into a clean, structured format to enable accurate business reporting.

Tech Stack:
- Tool: PyCharm (Jupyter Notebook)
- Language:Python
- Library: Pandas

 Data Cleaning Steps:
- Format Standardization:Converted 'Order Date' and 'Ship Date' from text to DateTime objects.
- Data Profiling: Verified that the dataset had 0 missing values and 0 duplicates.
- Feature Engineering: Created 'Ship Days': Calculated the lead time for logistics analysis.
- Created `Profit Margin: Calculated the profitability percentage per item.

 Files Included:
- "Sample - Superstore.csv": Raw data source.
- "Cleaned_one_Superstore_Data.csv": Analysis-ready dataset.
- "Superstore_Data_Dictionary.xlsx": Full variable documentation.
- "Superstore_data_task1.ipynb": Python scripts for data transformation.
